# 设计决策记录（2026-10-04 访谈结论）

原始需求是一份「Firefox-only 纯前端 Logseq 式 Markdown 工具」的架构 prompt。下面是逐项压力测试后的结论；每条都已固化进 `PLAN.md` 与 `src/**/types.ts`。

| # | 议题 | 决定 | 理由 |
|---|------|------|------|
| Q1 | 语料与目标 | 目标数据是用户本机 iCloud 中的真实 Logseq graph（约 60 个 md，含 Tab 缩进、`title::`、非 outliner 行）。测试通过环境变量 `MDGRAPH_REAL_GRAPH` **原地只读**它，不复制进仓库；另造合成语料提交 | 真实语料最能暴露手写解析器的问题；个人数据不进仓库 |
| Q2 | 非 outliner 内容 | 严格 Logseq outliner 为主；顶格非 bullet 内容归为 raw 块（无子节点、深度 0），raw 块可整块编辑 | 通用 Markdown 解析会让「块树 = 缩进」和幂等性同时失守；完全不可编辑则体验割裂 |
| Q3 | 块 ID 生成时机 | **只在被引用时**写 `id::`；原需求的「被编辑也生成」被否决。验收 5 补充：引用无 id 的块时，被引用块所在文件也允许变化 | 与 Logseq 一致；避免每次编辑都污染文件 |
| Q4 | 存储架构 | 只用 IndexedDB 存文件正文；索引启动时内存重建，不持久化。原需求的 OPFS + IDB 双持久化被否决 | 千文件级解析秒级完成；持久化索引只引入「索引与文件漂移」这一新 bug 源 |
| Q5 | Firefox 验证 | Playwright Firefox（已下载）跑 e2e 自动化验收 1–7；脚本 grep 封禁 Chromium 专有 API；用户另装了桌面版 Firefox 157 供人工验收 | 本机原本没有 Firefox；人工看 Network 面板不可复跑 |
| Q6 | 工作区与重导入 | 单工作区；导入 = 全量覆盖，有未导出改动时先警告并提示导出 | v1 工作流是导入 → 编辑 → 导出 → 手动覆盖；逐文件合并 UI 成本高 |
| Q7 | 导出粒度 | 全量 zip、仅改动 zip（默认）、单页 md；保留相对路径；导出后清 dirty | 「仅改动」直接服务于手动覆盖回原目录 |
| Q8 | 页面身份 | `title::` 覆盖文件名且文件派生名保留为别名；解码 `%2F` / `___` 命名空间；大小写不敏感；被引用无文件的页面为虚拟页；v1 不新建文件 | 兼容 Logseq 是核心价值，否则反链会漏 |
| Q9 | 编辑器渲染 | Logseq 式：失焦渲染、聚焦 textarea 显示原文；行内渲染手写极简 | 没有渲染态就没有可点击的链接与反链跳转 |
| Q10 | 反链上下文 | 引用块 + 面包屑（页面 › 祖先…）+ 折叠子块；排除本页自引用 | 原文「前后各一行」在块树中无明确含义 |
| Q11 | 交付形式 | 仓库 `~/work/project/github/mdgraph`；`PLAN.md` 按里程碑 + 验证门组织 | 最难的解析器放最前，幂等测试先于编辑器 |
| Q12 | 版本 | 跟随 create-vite 当前默认（React 19 / Vite 8 / TS 6），不锁 React 18 | 没有依赖 18 的理由 |
| Q13 | journals 页面名 | 硬编码 Logseq 默认格式 `yyyy_MM_dd` ↔ `MMM do, yyyy`，不解析 config.edn | 用户 graph 使用默认格式；二十行代码换取正确反链 |
| Q14 | `alias::` | v1 不做，记入 README 限制 | 用户 graph 从未使用 |
| Q15 | 编辑态属性行 | 显示除 `id::` 以外的属性行；`id::` 隐藏并原位保留 | 与 Logseq 一致，避免误删 id 打断引用 |
| Q16 | 分工 | 主会话（Claude）负责规划、契约、集成与复核；`worker` 子 Agent 按里程碑在 worktree 实现；Codex 只做对抗性审查（解析器）与独立验收（真实 Firefox） | 建造者与审查者分离；M1/M2、M4/M5 两组可并行 |
| Q17 | 启动方式 | 主会话直接编排 worker 与本机 Codex CLI，用户不需手动启动 | 用户要求由主会话统筹 |

## 原需求中被修正的地方
1. 「被编辑过时生成 ID」→ 删除（Q3）。
2. 验收 5「只有该块所在文件变化」→ 增加跨文件引用例外（Q3）。
3. 「正文放 OPFS、索引放 IndexedDB、两者持久化」→ 只用 IndexedDB，索引不持久化（Q4）。
4. 反链「前后各一行」→ 面包屑 + 子块（Q10）。
5. React 18 → 当前默认版本（Q12）。
6. 未定义的空白：非 outliner 内容（Q2）、页面身份规则（Q8、Q13）、重导入冲突（Q6）、导出粒度（Q7）、渲染模式（Q9）、属性行编辑（Q15）。
